# Chapter 3 marks the Cyrillic letters with xml:lang="rus" (ISO 639-2).
# An HTML lang value is a BCP 47 tag, and that tag for Russian is "ru".
# The letters and their text stay as they are. Changing the source tag is
# left to the later source cleanup.
.*Bad value “rus” for attribute “lang”.*

# The constants section has one paragraph with xml:lang="math", copied from
# the DocBook source. "math" is a reserved BCP 47 tag, so the checker
# rejects it. The paragraph text is unchanged. The source change is the
# later cleanup, not this markup switch.
.*Bad value “math” for attribute “lang”.*
